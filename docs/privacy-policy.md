# Privacy Policy

**Last updated:** September 19, 2026

Fanel is a self-hosted application designed to allow users to manage and access their own Fanel server.

## 1. Data collection

Fanel does **not collect, store, or transmit personal data to the developers of the application**.

The Android application does not use:

* Advertising or tracking services
* Analytics services
* User profiling
* Third-party advertising SDKs
* Developer-operated cloud storage
* Developer-operated user accounts

The application does not require users to create an account with the developers of Fanel.

## 2. Self-hosted data

Fanel is designed to be self-hosted.

Any data created or managed through Fanel is stored on the user's own Fanel server and infrastructure. The developers of Fanel do not have access to this data.

The user is responsible for the security, configuration, backups, and access control of their self-hosted installation.

## 3. Network connections

The Android application connects to the Fanel server configured by the user.

The server address is chosen and configured by the user and may point to a local network address, a private network, or a publicly accessible server.

Fanel does not send application data to a developer-operated server.

## 4. Artificial Intelligence

Fanel may provide functionality that uses artificial intelligence.

AI processing is part of the self-hosted Fanel server and is not operated by the developers of the Android application.

Depending on the configuration chosen by the administrator of a Fanel installation, information may be sent from the self-hosted server to an external Large Language Model (LLM) provider.

For example, a self-hosted installation may be configured to use a third-party AI provider. In that case, the data transmitted to that provider is determined by the configuration of that Fanel installation and is subject to the privacy policy and terms of that provider.

If a local AI model is configured, the data can remain entirely within the user's own infrastructure.

The Android application itself does not independently send user data to an LLM provider.

## 5. Third-party services

Fanel does not require any third-party service operated by the developers.

A self-hosted installation may nevertheless be configured by its administrator to use third-party services, such as external AI providers or other integrations.

Those services are outside the control of the Fanel developers and are governed by their respective privacy policies.

## 6. Data security

Because Fanel is self-hosted, the security of the stored data depends primarily on the configuration and security of the user's own infrastructure.

Users are responsible for securing their Fanel server, network, credentials, certificates, backups, and any third-party integrations they configure.

Using HTTPS is recommended when accessing a Fanel server over an untrusted network or the public Internet.

## 7. Children's privacy

Fanel does not knowingly collect personal information from children or adults because the application does not operate a developer-controlled data collection service.

The data stored by a self-hosted Fanel installation remains under the control of its administrator.

## 8. Changes to this policy

This Privacy Policy may be updated when the functionality or privacy characteristics of Fanel change.

The latest version will be made available with the application and its source code.

## 9. Contact

For questions about this Privacy Policy or the Fanel project, please use the contact information provided in the official Fanel project repository.

**Fanel is open-source and self-hosted. The application does not operate a centralized service that collects user data.**
